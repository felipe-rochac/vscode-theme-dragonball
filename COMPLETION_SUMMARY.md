## 🎨 Usage Examples

### VS Code Settings
```json
{
  "editor.fontFamily": "'Fira Code', monospace",
  "editor.fontLigatures": true,
  "editor.semanticHighlighting.enabled": true,
  "workbench.colorTheme": "Dragon Ball Piccolo"
}
```

### Theme Selection
1. Open VS Code
2. Press `Ctrl+K Ctrl+T`
3. Select any "Dragon Ball" theme
4. Enjoy professional syntax highlighting!
